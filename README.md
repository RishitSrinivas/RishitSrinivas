## 🚀 Featured Projects

### 🧬 [ZEROg](https://gravityzero.space)

**Multi-agent space-biology discovery engine**

Built a multi-agent system that scans NASA Open Science datasets and surfaces ranked biomedical research leads while the scan is running.

* Indexed **612 spaceflight studies**
* Processed **184M gene-expression values**
* Tracks roughly **47 research leads**
* Built around agent orchestration, scientific data retrieval, and live ranking

### 🥗 Weight Wellness

**Clinical grocery & nutrition assistant**

Built a web application for the Weight Wellness clinic at **UT Southwestern Medical School** that helps patients turn clinical nutrition guidance into affordable grocery decisions.

* Designed for roughly **350 patients/month**
* Compares grocery prices and shopping routes
* Indexed **191 clinical handouts**
* Built a RAG chatbot that answers questions using approved clinical materials
